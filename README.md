# ReplayMod-NeoForged

Unofficial [Replay Mod](https://github.com/ReplayMod/ReplayMod) port for **NeoForge 1.21.1**, based on [ferriarnus/ReForgedPlay](https://github.com/ferriarnus/ReForgedPlay) (1.20.4).

Do not ask for support on the official Replay Mod GitHub or Discord.

Build: `./gradlew remapJar` — jar in `build/libs/`.
